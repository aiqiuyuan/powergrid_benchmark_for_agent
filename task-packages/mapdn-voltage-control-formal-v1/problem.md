# MAPDN 正式局部电压控制

在固定 33 节点案例中改进六台光伏逆变器的局部无功控制。每台设备每三分钟仅获得一次当前区域观测并提交一次动作，可保存自身历史；不能获得其他控制器状态、未来轨迹、全网模型或额外潮流查询。完整接口与评分见 [instruction.md](instruction.md)。

案例是资格实验后冻结的 2012-02-03 完整 480 步。初始动作全零、无额外噪声，容量由完整来源数据固定。共同 starter 为同信息松弛 droop。开发时限为 43200 秒；过程反馈预算由外部实验配置指定，终评独立回放截止时唯一产物。n=0 无目标过程反馈，n>0 至多使用 n 次受保护完整案例反馈；候选错误同样消耗已接受调用。

优化先满足整日电压约束，再降低真实有功网损电量；无功使用量仅诊断。局部规则可能使用区域电压与负荷及自身历史，不能用共享状态绕过信息边界。
