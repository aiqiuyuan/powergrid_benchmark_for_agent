# RTE ABC／X15任务包准备完成说明

日期：2026-10-15。任务：`rte-maintenance-abc-x15-v1`。

## 已完成

1. **落实新研究设计。** ABC45完整实例开放开发与官方checker本地自测；X15仅由可信评测端持有。过程每例900秒，15路并行；冻结后每例5400秒单独评测，不回流。n统计完整X面板受理次数，ABC自测不计n。X同时参与反馈和终评，不声称独立未见泛化。
2. **备齐全部原始数据。** 固定官方commit，取得并核验B组；60例共23.31GB，完成原归档逐文件匹配、SHA256、流式JSON结构和风险向量长度检查。60个输入归一化常数已锁定，三例与旧函数位级一致。数据只在本地准备，GitHub不上传大型实例。
3. **实现新版原生task。** 独立开发／评测构建上下文，通用solver接口，15进程并行、不同CPU和UID、预算监督、清理及确定顺序汇总。官方checker保持原版，反馈只回传约定汇总；有效性与评分器完成状态分开。
4. **准备两档生命周期。** 过程入口固定900秒；原生终验保留900秒不回流结果；独立冻结工具／5400秒工具绑定最终源码摘要并拒绝覆盖报告。90分钟档需随后显式启动，不会自动进入过程反馈。
5. **修复必要运行问题。** 修正并行争用同核，禁止候选自行扩大CPU affinity，修正输出父目录的权限，防止候选替换目录入口干扰可信清理；补齐verifier产物目录、oracle入口和metric声明。数据准备采用流式归一化，避免整读数GB JSON。不改旧A4／X04任务、历史实验或框架全局运行逻辑。
6. **同步公开文档和测试。** 新增决定0006、配置操作说明、可移植源码包和独立CI测试；README、公平比较文档、RTE卡新增§13及历史政策覆盖说明已同步。原先X04选择与原赛资料保留供追溯。
