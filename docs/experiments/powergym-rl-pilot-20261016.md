# PowerGym PPO / 整数 SAC 单 seed pilot（2026-10-16）

本轮参照论文公开设置，新增 PPO 与整数 SAC 的独立实现，并在当前冻结 benchmark 条件下各完成40,000次真实训练交互。范围为34Bus标准负荷、每算法seed=0，另存并独立评测固定20k检查点。固定40k最终策略均未通过8个留出日的末能量约束，benchmark质量均为0。本报告与[传统强参照补充](distribution-baseline-qualification-20261016.md)分开记账；本轮不冻结正式PowerGym主案例。

## 与原论文的关系

官方公开了环境与数据，维护者明确表示仓库未包含论文PPO/SAC训练代码；本次对固定官方提交的核验也未发现训练源码或权重。论文附录Table6给出了主要超参数，但未提供足以唯一恢复训练过程的完整配置、划分和seed身份。可以独立重实现方法，目前不能认证原Figure2曲线的数值可复现性。来源、逐项参数归属和缺口见[论文复现来源核验](powergym-rl-paper-audit-20261016.md)。

| 项目 | 本轮设置与归属 |
|---|---|
| PPO论文参数 | Adam、lr=3e-4、gamma=.95、clip=.2、batch=64、rollout=512、entropy=.01 |
| SAC论文参数 | Adam、lr=3e-4、gamma=.95、batch=256、MLP512×3、entropy=.4 |
| PPO补齐假设 | 64×2/tanh、epochs10、GAE=.95、value_coef=.5、grad_clip=.5、advantage归一化 |

| 动作机制 | PPO按设备分解categorical；SAC使用straight-through Gumbel-Softmax整数重参数化，每设备一个标量进入critic |

这不是原生旧Gym环境的逐位复现。新基线继承当前snapshot执行、固定tap设置和滞后观测；终评要求每台电池末能量偏差≤1kWh，额外qualification再核对实际终端功率积分≤1kWh。训练保持论文vanilla reward，末SOC权重为0，没有事后添加惩罚。论文奖励、真实物理指标和硬约束有效性分别报告。

## 数据、反馈与检查点

固定官方源重建34Bus全部16条24小时packed profiles，独立8/8划分：训练`[0,2,3,4,5,7,10,11]`，留出`[1,6,8,9,12,13,14,15]`，split seed=0。显式文件排序和源行映射已记录；原作者split身份未知，packed-profile留出也不证明日历来源独立。

每120个训练交互评测全部8个留出profile，共333次过程诊断，再做40k最终评测；不按留出成绩择优、早停或调参。20k只保存检查点，通过独立入口评测；40k使用最终固定权重，另从保存权重独立评测核对。训练40k含1666个完整episode和最后16步，未完成训练episode不充当终评。p000属于训练集，仅作已见案例描述；p006/p015为留出，已包含于8条总体，不能重复加入平均。

训练反馈预算与正式Famou的n轨道不同；本批是额外算法参照，不是n=0/1算法开发run，也不构成同开发预算排名。

## 首次适配失败保留

v1的PPO / SAC分别在第1109 / 1660个物理训练步停止，完整日志为1108 / 1659条；没有20k/40k成绩。合法反向潮流使旧可选损耗比诊断为`None`，训练入口误将它作为必需奖励。独立审计精确复现训练和失败动作，确认物理量有限，并复核全部176条已完成诊断日。

v2只修新RL奖励层，按上游NumPy除法与原Python clamp顺序处理signed ratio与零源边界；旧物理模型、诊断、算法、超参数、数据、seed和预算不变。新增真实反送电完整日与零点回归。v1协议、47文件快照、失败和日志保留；v2另冻48文件并从头运行。独立审查确认旧停止点之前的训练路径逐项相同。此次属于基础适配修正，不能包装为调参改进。
