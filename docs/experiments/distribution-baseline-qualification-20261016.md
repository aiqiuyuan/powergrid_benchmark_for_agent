# MAPDN / PowerGym 强基线补充与选例复核

**补充实验已完成：MAPDN 16条完整日、PowerGym 45条完整日，全部通过动作、时域和各自能量验收。结果要求撤回此前对电压难度的部分判断。** MAPDN 四个候选日的单步局部反馈均达到100%电压合规，仍可比较安全约束下降损。PowerGym 34Bus强搜索只剩上游边界的微小越限，123Bus标准案例静态设备即可全天合规；目前不据此冻结正式混合设备主案例。

本批追加于[第一次选例实验](distribution-case-selection-20261016.md)，不替换其数字、源码、失败或旧n=0/1候选。案例、算法、参数、权限与预算先写入[主协议](../../configs/distribution-baseline-qualification-20261016.json)，PowerGym数值设置另按正式运行前冻结的[数值补充协议](../../configs/distribution-baseline-qualification-20261016-numerics.json)执行。没有运行新的Famou演化或集群作业。

差距为`(同CR局部损耗 / OPF损耗 - 1)`，仅描述已测方法与数值参考，不是可证明的最优差距。1月日保留第一轮更好的局部控制，不能用新方法较高损耗夸大空间；其余三日第一轮低损耗droop未达到100%CR，不能与安全参考直接比较纯损耗。

## PowerGym：设备、储能与边界诊断

25条新参考和20条匹配校准全部完成24步，均符合原每电池终态账面能量±1kWh。新储能参照还逐台要求实际净能量绝对值≤1kWh，保留命令能量、实际端口积分、吞吐、舍入及裁剪残差。**这是容差内能量中性，不是严格零净能量**。搜索是有限启发式，储能未联合重搜全部设备；自由搜索选idle不能证明电池在所有策略中都无用。

**34Bus的严格CR不等于明显持续电压失控。** 独立按原动作重放并定位每个母线后，三个当前强搜索的全部剩余越限只在`sourcebus`和`800`，最大超界分别为2.8334×10⁻⁶、2.1398×10⁻⁶、2.6986×10⁻⁶p.u.；其余馈线母线全部24小时合规。原0.95–1.05窗口与评分未修改，不通过排除母线或放宽容差把成绩改成100%。该残差不足以支持把34Bus认定为显著持续电压难例。

三个34Bus强制活动储能参考均有250kWh实际吞吐，符合双能量门槛，却使越界积分分别升为0.0148807、0.0115685、0.0213686pu·h。p0和p15的损耗虽降低，电压程度不同，不能称为纯损耗改进。原始失败和更差参考都保留。

123Bus标准日的静态设备已经全天合规。相同设备计划加储能后损耗从798.7283降至797.2316kWh，仅0.187%；各电池实际净能量约为`[0, 0, 0.498874, 0.290050]`kWh，最终账面能量为`[1000,1000,999,999]`kWh。微小收益发生在冻结的±1kWh容差内，不足以认证强跨期储能挑战。

123Bus压力日显示有限储能贡献：越界积分下降约20.50%，CR从75%升至79.17%，但最低电压仍约0.94693p.u.，尚无全天电压可行参考。无电池与含电池损耗分别5437.0089/5434.9116kWh，因CR不同不作纯损耗差距解释。压力轨与标准轨继续分开。

完整45条指标、每电池能量和操作数见[公开证据](verification/distribution-baseline-qualification-20261016-powergym.json)。操作代价不可省略：例如123Bus标准静态方案从规定初态移动92档tap，其操作成本计入原canary诊断评分。

## 数值设置、预算与独立核验

正式运行前，查询交错回归发现DSS热启动历史会影响实际端口功率、半整数能量舍入和下一步投影。因此另冻数值协议：所有查询与最终独立24步重放统一使用容差1e-10、重建Y矩阵和冷启动；保留原Generator `Q=P/pf`、投影、实际功率积分及整数舍入，不添加舍入epsilon。9组网络/seed随机交错试验共216小时均与独立重放逐项一致。

为区分数值设置与算法变化，旧四方法在同五案例全部重跑。20条严格CR、tap和cap操作数与旧记录完全相同；最大损耗差0.064753kWh，最大越界积分差0.00103787pu·h，最大相位×时间合规率差0.00014988。完整前后对照在PowerGym证据内；不能把全部改善归给新算法，也不能覆盖旧分数。

- MAPDN每案例每方法上限50000次显式潮流/1800秒。16条合计55346次潮流、各run耗时合计518.95秒；迭代内部潮流和独立终态复核均计入。没有迭代封顶、物理失败或预算耗尽。
- PowerGym每案例全部9方法共享200000次显式潮流/1800秒。45条合计162859次、各case耗时合计77.01秒；不含DSS编译内部调用。无预算耗尽，最终参考均有效；搜索内部不符合能量条件的候选仍被拒绝。
- 独立审查匹配全部结果与marker SHA、原候选池及原始文件、MAPDN37项和PowerGym38项封板快照，重新计算物理指标、动作和能量；另用新后端重放全部45条PowerGym计划，逐步设备与能量一致。审计额外1125次潮流不混入原优化预算。MAPDN没有宣称再做一次完整优化或物理重放。
- 全仓184项单元测试通过，39项因可选条件跳过；真实后端定向MAPDN10项、PowerGym13项通过，限定范围静态/格式检查通过。PowerGym其中两项合成优化器测试在正式启动后补充，未称为封板前验证；执行生产源码没有变化，执行时测试副本仍保留。

上述耗时相加均不是从准备到结束的墙钟用时，也不认证候选进程隔离。源代码、协议、运行锁、结果与独立审计摘要见[复核索引](verification/distribution-baseline-qualification-20261016.json)。重放入口、权限和源码版权见[工具说明](../../tools/distribution_qualification/README.md)。

## 当前选例决定

1. **MAPDN：保留33节点2012-02-03作为安全约束下降损候选。** 主比较必须包含已达100%CR的单步局部反馈，OPF及迭代物理反馈分列权限；撤回旧电压缺口难度论据。最终排名、任务包与严格n仍须独立冻结验收。
2. **PowerGym：暂不冻结34Bus标准日为正式混合设备难例。** 三个入围日的强设备控制近饱和，当前搜索未证储能收益；123Bus标准仅作初始化/静态控制对照。
3. **123Bus压力日保留研究候选。** 已看到容差内中性储能的有限贡献，但未建立全日可行强参照，不能仅因网络更大或CR更低即发布正式题目。

论文PPO/SAC的独立复现与统一合同重训将另存实验，不混入本批基线或据其成绩事后更改案例、奖励和排名。本补充没有自动替换旧canary、重提n=0/1、认证严格n或将扩展家族改为`release_ready=true`。
