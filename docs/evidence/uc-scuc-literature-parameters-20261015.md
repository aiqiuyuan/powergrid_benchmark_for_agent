# UC/SCUC 文献参数核对

核对日期：2026-10-15。以下为公开原文的参数摘述，不是本项目已经完成的复现。论文年份与预印本版本分别标注；数据相近或网络同名不构成同实例、同模型证明。

| 来源与定位 | 原文研究目标和参数 | 本项目使用边界 |
|---|---|---|
| Knueven、Ostrowski、Watson（2020），[DOI](https://pubsonline.informs.org/doi/10.1287/ijoc.2019.0944)、[公开稿](https://optimization-online.org/wp-content/uploads/2018/11/6930.pdf)，§6.3、Tables 7–9 | 等价UC formulation的计算比较；Gurobi 8.0.1，gap 0.01%；RTS/CA 300秒、FERC 600秒。Dell T620、双Xeon E5-2670、256GB；除时间外采用默认求解器设置。表中时间为几何平均，超时以时限代入；gap使用调整后的几何平均。 | 支持分钟级预算与严格精度档。不能据此称单核HiGHS或端到端计时复现了原硬件；原文未将此设置明确为单线程。论文同时含网络配置，不能将公开56个铜板实例等同于其全部实验。 |
| Xavier、Qiu、Ahmed（2021），[DOI](https://pubsonline.informs.org/doi/10.1287/ijoc.2020.0976)、[公开稿](https://arxiv.org/pdf/1902.01697)，§4.1–4.2、Table 9 | 学习辅助SCUC加速；CPLEX 12.8.0、Julia 1.2；训练gap 0.01%、测试0.1%。九个欧洲网络，1888–6515母线；每系统300训练变体、50测试变体。环境为Xeon E5-2695v4、18核/36线程、128GB；测试使用专用节点。保留保证的组合约4.3倍加速；约10.2倍组合放弃该保证。 | 支持“近最优质量约束下加速”及0.1%准备目标。节点线程数不是已核实的CPLEX线程配置；不补造统一测试timeout。该文SCUC场景与PGLib铜板UC分开。 |
| Sugishita、Grothey、McKinnon，[2021 arXiv稿](https://arxiv.org/pdf/2110.12531)，§4、§4.1、§4.2、Tables 2/5 | CPLEX、Xeon E5-2670；200/600/1000机组派生UC。§4.1比较达到并证明0.5%/0.25%/0.1%精度的用时，整体时限20分钟；§4.2比较1/2/5分钟的可行解质量，使用CPLEX运行4小时的下界。训练样本生成预算24小时、8 CPU核，额外神经网络训练另计。 | 支持将达标时间与限时质量分开；4小时仅作为我们的参考准备预算依据。原文没有在所核对段落明确测试求解线程数/CPLEX版本，不补填。24小时训练不是Agent开发时限。 |
| Qin、Yu，[2023 arXiv v1](https://arxiv.org/html/2311.15216v1)，§V-A/B/C、Tables II–IV | 图学习辅助UC；24小时、1354母线；SCIP 6.0。32核AMD 3970X、3张RTX 2080 Ti；主要测试使用10分钟求解限额，比较成本、gap及时间曲线。训练/验证标签使用Gurobi，单例上限5小时；1000/100/100天划分。 | 作为固定预算解质量的补充范式；不将GPU学习方法直接放入本项目无GPU开源引擎主榜，也不把标签生成预算当作在线时间。 |

本项目采用的0.1%主目标、0.01%补充目标和300/600秒准备预算有以上文献依据；**端到端计时、单核/8GiB、PAR2与Reward、3次终评重放及难度门槛属于本项目设计选择**。这些设置仍需同平台校准，原文不为其实际可运行性背书。采用共同离线下界的“达到参考质量时间”也不同于算法自行建立上下界的证明时间。

当前任务结论、配置和发布条件见[task card §13](../task-cards/unit-commitment.md#13-文献对齐的研究目标与配置2026-10-15)与[计时评分合同](../protocol/unit-commitment-speed.md)。
