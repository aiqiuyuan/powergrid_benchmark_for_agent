# 配电网正式固定案例扩展

2026-10-16，根据选例与强基线补充结果，固定 MAPDN 33节点2012-02-03完整480步，以及 PowerGym 123Bus profile0、负荷倍率2.5完整24小时。二者分别用于局部信息下的安全与网损控制、混合设备软代价控制。选择发生在正式 n 组实验之前；不根据正式结果更换案例。

本扩展研究同一案例下受保护反馈预算 n 的作用，不声称按日期泛化、原论文分数复现或全局最优认证。既有选例报告中关于 PowerGym 尚未形成“全程电压可行且强储能挑战”的判断继续有效；这里冻结的是允许电压违规并计入代价的任务。

MAPDN 的完整有效轨迹如果所有母线×时刻电压合规，质量为 `0.5+0.5/(1+L_MWh)`；否则为 `0.5*CR_bus_time`。因此全日安全优先，安全后实际有功网损越小越好。无功代理项仅作诊断。六个 PV actor 各自使用一次当前局部观测和私有历史；额外迭代 droop、全网 OPF 的信息与潮流次数另列。

PowerGym 沿用适配轨的综合代价，质量为 `1/(1+V_pu_hours+L_kWh/1000+(cap_switches+tap_moves)/33)`。操作项的33是冻结的归一常数，不代表123节点设备数。动作、收敛和完整24步是硬条件，每台电池的初末整数能量差与真实端口功率积分均须在±1kWh内。电压违规是软代价，同时报告合规率。强 current-load 优化器与全日 oracle 均是权限更多的参照，不作为相同观测条件下的策略排名。

每题 `n=0/1/3/5/10`，各3次独立开发，共30次，开发上限12小时，不设累计 token cap。n 是受理过程终评的上限，允许未用完；已受理候选失败计次并返回0分，超额请求须在执行前拒绝。终评重放截止时唯一候选，不从过程历史挑最好版本。重复编号标识独立开发进程，不宣称控制不可配置的 provider sampling seed。
