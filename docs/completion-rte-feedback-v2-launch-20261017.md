## 1. 实际完成范围

新增可移植原生任务包 [rte-maintenance-abc-x15-v2](../task-packages/rte-maintenance-abc-x15-v2/README.md)，基于v1已跟踪源码构建；不携带巨型数据、私有框架、服务凭据、模型轨迹或原始X成绩。未修改v1任务包及原149文件源码锁。

本轮只改必要任务逻辑：面板聚合、完整反馈、指标名、ABC公开助手、题面及冻结工具；启动、agent、计n、截止与原生终验继续复用eval-in-loop／Harbor。没有增加新的评分网关、计数服务或自动回滚历史最好候选的机制。

| 内容 | 已实现行为 |
|---|---|
| 主排行 | 可行例数k优先；相同k再比较Q=sum(有效q)/15 |
| 标量 | reward=(k+Q)/16，指标名rte_x15_coverage_quality_900_v2 |
| 逐例目标 | 官方F、mean_risk、expected_excess和q；其他例失败也返回有效例目标 |
| 失败目标 | 目标字段为null，汇总质量贡献0，不制造有效目标值 |
| 反馈诊断 | 完整15例，AC／WA／RE／TLE、固定约束错误类别、退出码、候选墙钟、子进程RSS及单位 |
| 身份与完整性 | 候选SHA256、900秒预算、面板数量、evaluation_completed、汇总与逐例一致性 |
| 隐私与大小 | 只组装白名单字段，JSON完整且不超过16KiB；不返回输入、解、原日志、checker原文或私有路径 |
| 基础设施故障 | evaluation_completed=false，诊断单列；不伪装为15例候选失败或可用零分 |
| 公开ABC助手 | 使用相同聚合语义，分母是所选ABC面板数量，不能直接当X15成绩 |
| 冻结双档 | 同一候选摘要和receipt绑定两档；900秒主成绩、5400秒补充，不取最大值 |

`validity`及私有`reward-details.valid`继续表示全部实例可行；它们为false时，一次完整的部分可行评测仍可能有正reward。实际读取时应结合`evaluation_completed`、`feasible_count`及`all_cases_feasible`，避免再次把部分进步归零。

## 2. 本批科学设置

| 设置 | v2约定 |
|---|---|
| 任务 | RTE检修排程，ABC45开放开发，X15受保护面板 |
| 完整矩阵 | n=0／1／3／5／10，各3次独立开发，共15组 |
| 开发预算 | 上限43200秒，累计token不设上限；原生预留终验余量及实际开发时长如实记录 |
| 过程反馈 | 完整X15，每例900秒，15并行；一次完整面板受理计一次n |
| 权威主成绩 | 原生截止后900秒终验，不向开发agent回流 |
| 补充成绩 | 同一冻结源码，每例5400秒独立启动；不占n、不回流、不选优 |
| 最终提交 | 截止工作区solver.py，不自动恢复历史最高反馈版本 |
| 官方目标 | 原checker的F／均值风险／超额风险与输入尺度不变 |
| 开发资源 | 2CPU／32GiB，无GPU |
| 评分资源 | 15CPU／256GiB；每候选单核、16GiB地址空间 |
| 外层资源 | 21CPU／296GiB，含既有运行开销 |
| 模型与原生客户端 | 沿用统一原批次配置；当前实际模型和工具响应仍须本批验收确认 |

n=0仍可以无限次ABC公开自测；它限制的是X15受保护反馈，不代表“没有任何评分反馈”。X已参与自适应反馈，最终不能称为完全未使用的独立测试集。90分钟结果只用于观察较长求解时间的表现，不能替代15分钟主排行。

## 3. 本地验证

**33项全部通过**，使用Python3.12、NumPy2.2.6和SciPy1.15.3。测试从0／1／14／15可行覆盖排序、质量单调和固定分母开始，随后验证实现；微型实例确实经过候选子进程、并行runner和固定原官方checker。

主要覆盖：重复／缺失面板与错误协议拒绝、NaN／Infinity／布尔伪数值／非法尺度拒绝、有效目标保留、无效目标null、完整15行白名单JSON、大小上限与隐私、非法提交诊断、基础设施失败区分、官方源码和starter摘要、进程清理及冻结两档摘要一致性。

本地验证使用合成小例，部分进程测试采用secure=False，安全命令测试与静态检查不等于目标Linux沙箱已运行。它不证明真实模型已读取新反馈、不证明当前X15完整面板资源通过，也不代表正式15组已提交。详情见[任务包验证说明](../task-packages/rte-maintenance-abc-x15-v2/verification/README.md)。
