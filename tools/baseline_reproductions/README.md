# Fixed baseline adapters

These adapters support the separate [2026-10-19 baseline campaign](../../docs/task-cards-v2/baseline-reproductions-20261019.md). They contain no model-provider calls, historical solution schedules or protected target labels. They are not new developer repetitions. Full precision completed results, immutable campaign hashes and actual Job identities are recorded in the [evidence ledger](../../docs/task-cards-v2/evidence/baseline-reproductions-20261019.json).

| Entry | Purpose | Required runtime / comparison boundary |
|---|---|---|
| `goc/code1.py`, `goc/code2.py`, `goc/pmsc_baseline.jl` | Complete pinned PMSC heuristic and either soft or strict fixed-point response | Original native Julia project; PMSC0.12.0 commit5239af6. Full current-budget replay, with historical fast-fallback wrapper omitted |
| `rte_milp.py` | Independent mean-risk and feasibility MILPs | NumPy/SciPy and original RTE actor/checker contract; official risk is evaluated by the checker |
| `heftcom_models.py` | Generation/price-aware ridge, HGB, direct bids and explicitly named competition-inspired adaptations | NumPy1.26.4, SciPy1.16.3, sklearn1.6.1; CatBoost1.2.8 uses a separately identified offline extension with exact own-statm READ_FILE permission |
| `uc_egret.py` | Author EGRET Tight/Compact/Random1 copperplate formulations | EGRET28c324f, Pyomo6.9.5, HiGHS1.15.1 and original UC data/checker; Python runtime differs from Julia/JuMP starter |
| `distribution/mapdn_upstream.py` | Hash-checked upstream MADDPG/MATD3 training followed by causal480-step replay | Pinned MAPDN source/data/physics adapter and CPU Torch2.9.0; final400-episode checkpoint, seeds0–4 |
| `distribution/powergym_exact.py`, `distribution/cbat_sac.py` | Random and reconstructed PPO/integerSAC/hybridSAC on the exact123Bus stress case | Pinned PowerGym/OpenDSS and CPU Torch2.9.0;40000 actual transitions, seeds0–2; hybrid battery grid projection disclosed |

The GOC scripts expect native inputs at `$GOC_APP/native/case.{con,inl,raw,rop}`, stage1 outputs at `$GOC_STAGE1`, and an adjacent `baseline.json` containing `scenario` plus `code2_mode` (`upstream-soft-fp` or `strict-fp`). Set `GOC_CODE1_SECONDS` and `GOC_CODE2_SECONDS` to the declared current-case limits. The host runner enforces those deadlines independently. The archived Julia dependency manifest must match the pinned package tree; the version check alone does not verify a tree identity.

For HEFTCom copy the entry as `solution.py` with adjacent `method.txt` naming one value in `METHODS`. The original train/predict interface supplies only frozen legal training inputs and each day's legal features. GEB quantiles, SVK direct CatBoost and organizer spline are restricted-input adaptations, not recovered original competition systems. Fixed parameters do not use target-period checkpoint or hyperparameter selection.

For UC the physical checker is unchanged. Demand slack and reserve shortfall are forbidden. The adapter explicitly enforces equality balance because the pinned author copperplate helper misinterprets the presence of relax_balance=False and otherwise constructs generation >= demand. The original task requires equality; v4 rejected schedules are retained, and v5 adds must-run excess and renewable-curtailment native checks for all three formulations. Callback timestamps include imports, parsing, model construction and serialization. Equal HiGHS backend versions do not make Python/Pyomo and Julia/JuMP startup costs identical. The source-matched v5 native gate passed before the three corrected formal reference jobs were released; synthetic acceptance does not replace full-case physical validation.

Distribution references have simulator/reward/training-data access and learned-weight dependencies beyond the formal developer feedback budget and stdlib-only actor contract. Target PowerGym profile0 is included in the training pool. Final weights are never replaced by a better intermediate checkpoint. Hard terminal-energy failures retain `valid=false` and quality0; native Gym returns cannot replace benchmark validity or quality. The hybrid SAC is an independent reconstruction with continuous battery training and a named33-level projection at inference.

The public repository does not contain the complete private cluster orchestration or protected grading bindings. These files expose the numerical implementations for review; running a full case requires the pinned inputs, upstream packages, original runtimes and corresponding independent checker. See each task card for access and information restrictions.
